# PEPA · Centro de Mando de Ventas

Panel web del agente de ventas **Pepo**. Se publica en https://fransegura51.github.io/pepa-ventas/

- Instalable en móvil y ordenador (PWA).
- Datos en el Supabase del panel (tablas `ventas_contactos`, `ventas_correos` y `lista_espera`), protegidos por inicio de sesión.
- La clave `anon` de `config.js` es pública por diseño. Aquí NO van contraseñas, contactos ni claves secretas.
